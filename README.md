# Sprint 7 - Тестирование API Яндекс Самокат

## Описание проекта
Проект содержит автоматизированные тесты для API сервиса Яндекс Самокат.

Тестируемые ручки
1. Создание курьера
Успешное создание

Создание дубликата

Отсутствие обязательных полей

2. Логин курьера
Успешная авторизация

Неправильные учетные данные

Отсутствие обязательных полей

3. Создание заказа
С разными вариантами цветов (BLACK, GREY, оба, без цвета)

4. Список заказов
Получение списка заказов


Основные изменения:
Фикстуры для очистки данных - созданы в conftest.py для автоматического удаления курьеров после тестов

Вынесены вспомогательные функции - создан helpers.py для хранения общих функций

Добавлены аннотации Allure - каждый тест имеет понятное название

Убраны вложенные функции - все вспомогательные методы вынесены в отдельные модули

Упрощены тестовые классы - содержат только тестовые методы

Теперь проект соответствует всем требованиям: чистая архитектура, автоматическая очистка данных и понятная структура тестов.
