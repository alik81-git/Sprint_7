# Sprint 7 - Тестирование API Яндекс Самокат

## Описание проекта
Проект содержит автоматизированные тесты для API сервиса Яндекс Самокат.

Тестируемые ручки
1. Создание курьера
Успешное создание

Создание дубликата

Отсутствие обязательных полей

2. Логин курьера
Успешная авторизация

Неправильные учетные данные

Отсутствие обязательных полей

3. Создание заказа
С разными вариантами цветов (BLACK, GREY, оба, без цвета)

4. Список заказов
Получение списка заказов
